# After Day 2 — what goes to the course assignment

**These two days have no hand-in to the session teaching team.**  
You leave with a **project package** and **draft SRC DMP text** that you transfer into the host course’s assignment component 1 (DMP). The course owns deadlines, submission portals, and grading.

Use this page as a checklist before you submit to the **course**.

---

## What you should have by the end of Day 2

### Project package (folder + documentation)

- [ ] Clear folder layout (raw vs derived separated; docs findable)
- [ ] README that orients a stranger (purpose, people, status, how to navigate)
- [ ] Decision log (or equivalent) for major *why* choices
- [ ] Naming / versioning habit you can defend (prefer Office Online + §6.1-named downloads, or dated copies + log)
- [ ] Notes on sharing / access limits (“as open as possible, as closed as necessary”)

### Partial SRC DMP (six areas only, in these sessions)

Paste targets and exact template wording: [Assignment component 1: DMP](assignment-1-dmp.md).

- [ ] **Data description** (both prompts) — Day 1  
- [ ] **Documentation** — Day 1  
- [ ] **Storage** — Day 2 App 1  
- [ ] **Security** — Day 2 App 1  
- [ ] **Data quality** — Day 2 App 2  
- [ ] **Who is responsible** — Day 2 App 2  

Mark pasted text as *draft* until you finish the rest of the template for the course.

### AI-use disclosure

- [ ] If you used AI in App 2 (either day): keep prompt + output; note what you changed; disclose per course / KI rules  
- [ ] Full disclosure template (when published): issue #15 materials in Canvas

## What these sessions do **not** replace

- **Assignment component 2** — the **data collection protocol** (other course parts). Here you only note where instruments and versions live.
- Other SRC questions: legal, ethics, accessibility, long-term storage, software, DOI, costs, general information. Finish those for the course assignment.
- Programming, containers, or a Git course (see K8F6106 if you need Git depth).

Submit the DMP (and whatever else the course requires) through the **K9F5740 course** Canvas assignment / DMPonline path your course director names — **not** through a separate hand-in for these two days.
