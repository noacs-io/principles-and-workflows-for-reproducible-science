Exercise 1 — compare two project folders

Your team opens two synthetic project folders for the same fictional bednet study (Exercise 1 on Google Drive):

  • bednet-survey-transnzoia
  • bednet-study

Use the 5-year rubric as your guide.

  1. Compare the folders with the rubric questions. For each difference that matters, also ask: does this help or block someone recreating the work from the same data and analysis?
  2. As a team, agree on 2–3 findings and post them on the shared board. Name the folder and which rubric question it answers.
  3. Join the whole-group discussion of the board posts. Be ready to say why you arrived at those findings.

Exercise 2 — your project folder and DMP draft

Create or improve a project folder for one study in your PhD project. Add or update a short README explaining the study and how its files are organised. Keep the 5-year test in mind from Exercise 1.

  1. Create or improve the folder and README (manual drafting is fine).
  2. If you use AI: prefer Microsoft Copilot because it is supported by KI.
  3. Use your folder and documentation work to draft answers under data description and documentation in the DMP template.
  4. Within your team: Take turns briefly showing your folder, README, and DMP drafts (about 2–3 minutes each). Could a colleague find their way around the project? What would make it easier to understand? Note one improvement to make before Day 2.
  5. As a team, post 2–3 patterns or problems on the shared board.
  6. Join the whole-group discussion of the board posts.
